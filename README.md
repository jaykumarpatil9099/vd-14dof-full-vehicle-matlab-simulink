# 14-DoF Full-Vehicle Model — MATLAB & Simulink

A standalone Simulink implementation of a 14-degree-of-freedom full-vehicle dynamics model — body (heave/pitch/roll/yaw) coupled to per-corner unsprung dynamics, wheel rotation, drivetrain, brakes, anti-roll bars and a Pacejka Magic Formula tyre, built around a formula-class parameter set.

**Author:** Jaykumar Patil
**Status:** Model wiring under review — frequency-domain results match analytical hand calculations to within ~2 % on the heave/wheel-hop modes, but the lateral / yaw response shows the expected qualitative trends rather than fully calibrated correlation. See `00_admin/02_known_caveats.md` for the current punch list.
**Toolchain:** MATLAB R2024a · Simulink

> **Read this first:** [`05_reports/14dof_overview.md`](05_reports/14dof_overview.md) — the one-page summary of the model, the studies, and the current state of correlation.

## What this is

A single Simulink model that couples the ride-domain shaker-rig physics (heave + pitch + roll + four unsprung-mass vertical DoFs) with the handling-domain bicycle-style physics (longitudinal + lateral + yaw + four wheel rotational DoFs), driven by a real engine map, an 8-speed gearbox, brakes with adjustable front/rear balance, and per-axle Pacejka tyres.

It is the natural endpoint of the vehicle-dynamics modelling progression — once you have validated the quarter-car, the 4-DoF half-car, and the 7-DoF shaker rig in isolation, the 14-DoF is what you build to study the combined ride/handling response that none of the smaller models can give you.

This repo is a standalone extraction of the 14-DoF model so it can be used (or audited) without dragging in the rest of the modelling toolkit. The wider library lives at [`vehicle-dynamics-models-matlab-simulink`](https://github.com/jaykumarpatil9099/vehicle-dynamics-models-matlab-simulink); the lap-time simulator that consumes this kind of model lives at [`gt3-lap-time-simulator`](https://github.com/jaykumarpatil9099/gt3-lap-time-simulator).

## DoF inventory (14 total)

| DoF group | Count | States |
|---|---|---|
| Sprung body | 6 | z_s, θ (pitch), φ (roll), x, y, ψ (yaw) |
| Unsprung vertical | 4 | z_us,FL, z_us,FR, z_us,RL, z_us,RR |
| Wheel rotation | 4 | ω_FL, ω_FR, ω_RL, ω_RR |

(Heave + pitch + roll cover ride; x + y + yaw cover handling; wheel spin closes the loop on traction, braking, and longitudinal slip for the Pacejka block.)

## Studies included

### 1. Aero study — longitudinal performance
Straight-line acceleration with two aero configurations (low downforce vs high downforce). Captures the trade-off between drag-limited top speed and downforce-limited acceleration. Output channels: longitudinal acceleration vs speed, slip ratios per axle, gear engaged. See [`04_studies/aero_study/`](04_studies/aero_study/).

### 2. Vehicle comparison — handling response
Same handling manoeuvre (steering input over a fixed time history) run with two parameter sets — formula-class default vs road-car (heavier, longer wheelbase, no downforce, softer suspension). Channels: yaw rate, lateral acceleration, side-slip angle, X/Y trajectory. The contrast makes the effect of mass distribution, downforce, and tyre choice immediately visible. See [`04_studies/vehicle_comparison/`](04_studies/vehicle_comparison/).

### 3. Frequency-domain analysis
A reusable FFT helper with automatic zero-padding to the next power of two, applied to:
- Sprung-mass vertical acceleration → heave natural frequency (~ 3 Hz)
- Unsprung-mass acceleration → wheel-hop natural frequencies (~ 27 Hz front / rear)
- Yaw rate from the handling study → yaw response peak (handling-domain)

The 7-DoF shaker-rig validation in the wider toolkit already proved the heave/wheel-hop physics of the ride side to within 2 % of hand calculations; this 14-DoF run is a sanity check that those modes survive once the longitudinal and lateral degrees of freedom are added. See [`04_studies/frequency_analysis/`](04_studies/frequency_analysis/).

## What works, what doesn't

**Works**
- Static equilibrium — set inputs to zero, all states stay at zero. Spring preloads and static tyre forces cancel gravity at the equilibrium point.
- Aero scaling — F_DF and F_drag scale with V² as expected.
- Heave / wheel-hop natural frequencies — match the closed-form approximations sqrt((k_s + k_t)/m_us) / (2π) within ~2 %.
- Pacejka peak μ behaviour — per-axle coefficients reproduce the expected front-vs-rear lateral grip asymmetry under slip-angle sweeps.

**Under review**
- A handful of internal sign-convention crossovers between the roll equation, the lateral-load-transfer brackets, and the ARB redistribution terms — the model converges and produces sensible-looking responses, but the lateral / yaw correlation is qualitative rather than calibrated. This is the next milestone (see [`00_admin/02_known_caveats.md`](00_admin/02_known_caveats.md)).

**Out of scope**
- Tyre temperature and wear (would need a thermal/wear model on top of the Magic Formula)
- Multibody suspension kinematics (the model uses lumped corner spring + damper + ARB rather than an A-arm/wishbone linkage)
- Driver model (manoeuvre inputs are scripted, not closed-loop)

## Background

Built as part of the M.Sc. Interdisciplinary Engineering (Automotive) at Hochschule Trier.
